# Sponsor Model

## Purpose

Enable mission-aligned organizations to sponsor AI access for people, schools, and communities in Nepal.

## MVP Scope

- Public sponsor package listing
- Public sponsor interest form
- Lead capture in backend database

## Packages (Seeded)

- Bronze: sponsor basic user credits
- Silver: sponsor school/district access
- Gold: sponsor larger community program

## Lead Capture Flow

1. Sponsor reviews packages on frontend
2. Sponsor submits interest form
3. Backend validates minimum required fields
4. Lead is saved with status `new`
5. Team follows up manually (outside MVP)

## Out of Scope (MVP)

- Payment processing
- Sponsor authentication
- Sponsor dashboard
- Invoices and billing automation
